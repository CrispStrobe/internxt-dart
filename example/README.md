# internxt_client examples

An unofficial Dart client + CLI for Internxt cloud storage. See the package
README for full command and API documentation.

## CLI

```sh
dart run internxt_client:inxt --help   # list, upload, download, sync, WebDAV
```

## Library

```dart
import 'package:internxt_client/internxt_client.dart';
// Log in and drive the account programmatically — see the README for the full
// API (auth, drive listing, encrypted upload/download, WebDAV bridge).
```
